# Google Sheets ＆ Apps Script 後端部署指南 (內部 PoC 概念驗證版)

> **⚠️ 重大資安與個資隱私警示（部署前必讀）：**  
> 1. **未經驗證之個資外洩風險**：現有 [`Code.gs`](file:///Users/ethanchen/Desktop/115-1/匹克球學習社群/backend_gas/Code.gs) 中之 `doGet(e)` 函式會將試算表內的學生**真實姓名、學號、系所年級、LINE ID、Email** 等欄位全數無遮蔽輸出為 JSON。  
> 2. **存取權限陷阱**：若依傳統教學將 Web App 存取權限設為「所有人 (Anyone)」，任何取得該 URL 的第三方皆可於瀏覽器無須任何帳號密碼直接下載全體報名學員之完整敏感個資！  
> 3. **處置決策**：**本腳本目前僅供內部研發測試與概念驗證 (PoC)，嚴禁在正式環境中對外公開部署或作為線上報名正式端點！** 正式上線或送件應改用校內官方報名表單、去識別化欄位脫敏或 Google Forms。

---

## 📌 一、 腳本功能說明 (內部測試)

1. 當內部測試網頁送出報名時，資料寫入 Google 試算表。
2. 自動在試算表中建立「報名名冊」、「出席簽到」與「器材借還」工作表。
3. 支援內部模擬點名與器材借用寫入。

---

## 🔒 二、 安全防護修改建議 (若未來需正式部署)

若後續專案欲將此腳本投入正式運作，必須先完成以下資安防護修訂：

1. **移除或鎖定 `doGet(e)`**：
   - 將 `doGet(e)` 讀取資料庫名冊之功能刪除，或加入 `token` 密鑰驗證。
   - 對外部僅開放 `doPost(e)` 單向寫入報名，禁止外部任意讀取名冊。
2. **敏感個資欄位去識別化**：
   - 回傳資料前，學號與聯絡資訊必須進行遮蔽脫敏（如 `4114*****`、`0988***889`）。
3. **存取權限收斂**：
   - 權限僅限「僅限我自己」或「中興大學機構內部使用者 (NCHU Domain)」，避免網址外流導致全網爬取。

## 🛠️ 三、 內部 PoC 部署流程 (僅限內部受控測試)

### Step 1：建立 Google 試算表
1. 打開 [Google Drive](https://drive.google.com/)。
2. 建立新試算表，命名為 `115-1 匹克球學生學習社群 (測試資料庫)`。

### Step 2：開啟 Apps Script 並貼上程式碼
1. 點選「擴充功能」 ➡️ 「Apps Script」。
2. 清空原本內容，貼上專案 [`Code.gs`](file:///Users/ethanchen/Desktop/115-1/匹克球學習社群/backend_gas/Code.gs) 程式碼並儲存。

### Step 3：內部權限受控部署
1. 點擊「部署」 ➡️ 「新部署」 ➡️ 「網頁應用程式」。
2. 執行身分選擇「我」；**誰可以存取建議選擇「僅限我自己」或機構內部**，進行內部除錯驗證。
3. 取得之 Web App 網址僅供本機 `dashboard.html` 內部除錯填入，切勿公開於任何公開 GitHub 儲存庫或論壇。
