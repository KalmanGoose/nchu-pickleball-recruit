# Google Sheets ＆ Apps Script 後端部署超簡單三步指南 (60秒完成)

> **這份腳本做到了什麼？**
> 1. 當新同學在網頁點擊「送出報名」時，資料會**直接自動寫進你的 Google 試算表**！
> 2. 自動在試算表裡建立「報名名冊」與「出席簽到」工作表，標題列自動上色排版。
> 3. 不需要資料庫伺服器、不用花錢買主機，完全免費且安全。

---

## 🚀 60 秒部署流程 (只要做一次)：

### Step 1：建立 Google 試算表
1. 打開你的 [Google Drive](https://drive.google.com/)。
2. 點左上角「新增」 ➡️ 「Google 試算表」，將試算表命名為：  
   `115-1 匹克球學生學習社群 (資料庫)`。

---

### Step 2：開啟 Apps Script 並貼上程式碼
1. 在試算表上方選單點選：**「擴充功能」 ➡️ 「Apps Script」**。
2. 頁面開啟後，把編輯器裡面原本的 `function myFunction() {}` 全部刪除。
3. 打開專案裡的 [`Code.gs`](file:///Users/ethanchen/Desktop/115-1/匹克球學習社群/backend_gas/Code.gs)，將**全部程式碼複製並貼上**到編輯器中。
4. 點選上方的「儲存專案」磁碟片圖示（或按 `Ctrl+S` / `Cmd+S`）。

---

### Step 3：部署為網頁應用程式 (取得 API 網址)
1. 點擊右上角藍色按鈕：**「部署」 ➡️ 「新部署」**。
2. 點選左側齒輪「選取類型」 ➡️ 選擇 **「網頁應用程式 (Web App)」**。
3. 填寫部署設定（非常關鍵！）：
   - **說明**：`匹克球社群後端 v1`
   - **執行身分**：選擇 **「我」 (你的 Google 帳號)**
   - **誰可以存取**：務必選擇 **「所有人 (Anyone)」**（這樣外部網頁才能把報名資料送進來，但他們**看不到**你的試算表內容，只能寫入！）
4. 點擊「部署」。首次部署時 Google 會彈出權限確認：
   - 點「核對存取權」 ➡️ 選擇你的 Google 帳號 ➡️ 點左下角「進階 (Advanced)」 ➡️ 點「前往...（不安全）」 ➡️ 點「允許」。
5. 部署成功後，會看到一個 **「網頁應用程式網址」** (格式為 `https://script.google.com/macros/s/AKfycb.../exec`)。
6. **複製這個網址貼回給我（或貼在前端網頁設定中）**，後端就 100% 正式連線啟用了！
