## 二、 角色職責與權限矩陣表 (RACI 矩陣)

> **標記說明**：
> - **R (Responsible 實際執行)**：負責把事情做完的人。
> - **A (Accountable 最終負責/決策)**：擁有最終裁決權、審核驗收（通常由幕後總管把關）。
> - **C (Consulted 諮詢對象)**：提供專業意見（如學習諮詢顧問、總管）。
> - **I (Informed 告知對象)**：只需接收結果通知。

## 三、 115-1 關鍵時程與檢核點 (Milestones)

| 日期節點 | 項目 | 負責人 | 驗收標準 / 備註 |
| :--- | :--- | :---: | :--- |
| **送件前** | 確認 6 位成員名冊與 115-1 修課清單 | 召集人 / 全員 | 逐人核對，確認非當學期授課作業且無衝堂 |
| **送件前** | 學習諮詢意願與形式確認 | 召集人 | 聯繫體育室許銘華老師確認第 2 週與第 5 週諮詢 |
| **正式送件** | **教發中心系統送件** | 社群召集人 (龔依吟) | 依純文字版填入系統，核對預算剛好 8,000 元 |
| **第 1–4 週** | 執行聚會 1~4：教材與技術共學 | 全體成員 | 按鈕版六題教材、MediaPipe 節點測試、固定參數 |
| **第 5 週** | 執行聚會 5：體驗演練與流程整備 | 全體成員 | 內部分站試跑、動線整備、第二輪學習諮詢 |
| **第 6–7 週** | 執行聚會 6~7：兩場新手體驗與檢討 | 全體成員 | 累計目標 30 人次新手測試、前後測與 SUS 問卷 |
| **11/30 前** | 器材採購發票整理與經費核銷 | 財務 (吳佳叡) | 確認收據/發票具備學校統編（52024101）與明細 |

## 四、 雲端與本地端協作公約（防呆機制）

1. **單一真理來源原則**：
   - 所有企劃內容與預算規範一律以 Desktop 主稿 `01_115-1計畫申請書_退件修復完整版.md` 為準，衍生文件不得私自偏離主稿。
2. **單據即時拍照原則**：
   - 總務採購任何物品（球、握把布、膠帶、印刷），結帳當天必須立刻拍照上傳雲端，檢查統一編號 **`52024101`** 與明確品名。
3. **活動當日結清原則**：
   - 每次聚會結束後 24 小時內，紀錄組將現場照片存入雲端；48 小時內完成簽到名冊確認與填寫「討論紀錄表」。
4. **個資安全防線**：
   - 學員報名與測試資料一律採去識別化編碼（`SUB-01` ~ `SUB-30`），`backend_gas` 嚴禁未經驗證對外公開部署。
