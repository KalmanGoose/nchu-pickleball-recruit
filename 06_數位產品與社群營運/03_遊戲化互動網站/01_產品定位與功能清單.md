# 遊戲化/互動網站｜產品規格與 Backlog

> **定位**：破冰利器、提升學員留存率，以及向學校教發中心展示「跨領域數位創發」的亮點王牌。

---

## 一、 核心功能規劃 (MVP 階段)

### 1. 趣味心理測驗：「測出你的匹克球命定球風與推薦球拍」
- **目的**：讓完全不懂匹克球的新生/外系同學有參與感，並將測驗結果導流至 LINE 或 Google Sites。
- **題型設計 (3~5 題)**：
  - Q1：在球場上面對猛烈來球，你的第一反應是？ (A. 穩穩擋回去軟球 / B. 大力殺球對抽)
  - Q2：挑選運動裝備時，你最看重？ (A. 輕量控球手感 / B. 科技感與爆發力)
- **結果標籤**：
  - 「穩健廚房魔術師 (Dink 大師)」 ➔ 推薦 SLK 玻纖拍 / 碳纖 16mm 控球拍
  - 「進攻型火砲重砲手」 ➔ 推薦碳纖 13mm 速度拍

### 2. 規則情境大考驗 (Kitchen Rule Quiz)
- **目的**：解決初學者對 Non-Volley Zone 的理解誤區。
- **形式**：短秒數情境圖判斷（「這球算不算犯規？」），答對獲得社群虛擬徽章。

### 3. 社群練球打卡與段位成就榜
- **形式**：記錄出席次數與練球等級晉階（小白 ➔ 初階銅牌 ➔ 進階銀牌 ➔ 實戰金牌）。

---

## 二、 幕後開發與技術管理建議
- **技術棧建議**：HTML/Tailwind CSS/Vue/React 靜態單頁或獨立部署於 GitHub Pages / Vercel。
- **整合方式**：可在 Google Sites 中以 `<iframe>` 形式直接嵌入，兼顧便利性與展示效果。
