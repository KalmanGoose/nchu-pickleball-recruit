# LINE 官方帳號｜架構規劃與營運手冊

> **定位**：社群的「日常流量入口」與「學員互動中心」。透過自動化回覆與固定選單，大幅降低人工客服壓力。

---

## 一、 圖文選單 (Rich Menu) 6 宮格設計建議

建議在 LINE 後台建立「6 格版型」，按鈕配置如下：

| [按鈕 1] 🏓 零基礎新手指南 | [按鈕 2] 📅 近期練球/活動行事曆 | [按鈕 3] 🎮 匹克球測驗/趣味遊戲 |
| :---: | :---: | :---: |
| 導向：Google Sites 新手專區 | 導向：活動報名 / 行事曆連結 | 導向：互動遊戲網站連結 |
| **[按鈕 4] 🏆 社群積分與排行榜** | **[按鈕 5] 📍 球場位置與交通** | **[按鈕 6] 💬 聯繫召集人/幹部** |
| 導向：學員出缺席/等級名冊 | 導向：Google Map / 場地說明 | 導向：開啟 1 對 1 聊天室 |

## 二、 加入好友歡迎訊息 (Greeting Message)

```text

無論你是完全沒碰過球拍的「萌新小白」，還是想找球友互相切磋的「進階高手」，這裡都有專屬於你的位置！

👉 快速探索：
1. 點擊下方選單【零基礎新手指南】，3 分鐘看懂匹克球規則與廚房區秘密！
2. 點擊【近期練球行事曆】，立刻報名本週四的練球活動。
3. 挑戰看看我們的【匹克球互動遊戲】，測測你的匹克球球風與命定球拍！

有任何問題都可以直接在對話框留言，幹部小編會盡快回覆你喔！🙌
```

## 三、 關鍵字自動回覆設定 (Auto-reply Keywords)

| 觸發關鍵字 | 自動回覆內容建議 |
| :--- | :--- |
| **規則 / 計分 / 廚房區** | 推送「規則精華懶人包」圖文卡片，並附上 Google Sites 規則專題連結。 |
| **費用 / 球拍 / 租借** | 「社員免場租！社群提供 8 支體驗拍（木拍/玻纖/碳纖）免費借用，穿著運動鞋即可來玩！」 |
| **地點 / 球場** | 推送校內室外網球場/練習牆之詳細照片、Google 地圖定位與停車指引。 |
| **請假 / 取消** | 「若已報名臨時無法前往，請於活動前 24 小時至群組告知，以利候補球友進補喔！」 |
