## 二、 權限設置（Permissions）防呆建議

1. **幕後總管 (你)**：
   - 權限：**最高擁有者 (Owner)** 或 **完整管理員**。
   - 備份：定期將雲端中的填報檔案下載回本機，餵給 AI 統整。
2. **前台幹部（召集人、行政、總務、影音）**：
   - 權限：**「內容管理員」或「編輯者」**。
   - 限制：禁止組員刪除母資料夾，僅能在各自分工的資料夾上傳與修改。
3. **一般社員**：
   - 權限：**「僅限檢視 (Viewer)」**，避免誤刪重要的紀錄表或照片。
